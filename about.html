Patriot Command

Plan Once. Save It. Launch It.

Patriot Command is a teacher-focused planning and instructional tool designed to make the daily classroom workflow simpler. Teachers can plan lessons, save them to a personal library, reuse previous work, and launch lessons directly into a classroom-ready teaching view.

Current Version

Version 1.0

Built for daily planning and instruction.

Our Purpose

Patriot Command was created to reduce repeated work and help teachers move smoothly from planning to instruction. It keeps lesson information organized, accessible, and ready when the school day begins.

Our Philosophy

Useful technology should support teachers rather than create more work. Patriot Command follows a simple principle: keep the tools practical, keep the process clear, and keep the teacher in control.

What Patriot Command Includes

  • A dashboard that identifies the current or next class using the school bell schedule.
  • A lesson planner for creating, saving, editing, and duplicating lessons.
  • A searchable lesson library with calendar and class filters.
  • A classroom teaching view for today’s scheduled lesson.
  • The ability to launch any saved lesson directly from the Library.
  • Teacher settings for identifying classes and personalizing the daily experience.

Created for Teachers

Patriot Command was designed and developed by ACSHS Library Media Specialist Maegan Renick as a practical tool for the daily needs of teachers at Allen County-Scottsville High School. It continues to grow through real classroom use, teacher feedback, and a commitment to keeping the experience simple.
